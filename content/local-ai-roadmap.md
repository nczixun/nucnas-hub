先在现有电脑完成一次可重复的本机对话，再考虑界面、知识库和多人使用。这里不承诺某个配置的速度，也不要求购买新设备。

## 第一步：记录条件，区分本地与云端

先读 [本地模型基本概念](/ai/ollama-beginner-guide-2026/)，记录操作系统、内存、显卡及显存、可用磁盘空间。“完全私密”“无限免费”不是所有配置都成立的保证：模型来源、云端选项、外部工具和日志设置都需要检查。

**完成标准：** 能说明模型在哪里运行、哪些功能需要联网，以及准备使用它完成什么任务。

## 第二步：按官方步骤完成本机对话

以 [Ollama 官方快速开始](https://docs.ollama.com/quickstart)选择适合系统的安装方式和模型。官方快速开始区分本机模型与云端请求：本机模型不需要云服务 API key；不要把账号/密钥填入本机记录模板。先选硬件能承受的模型，下载完成后做一个不含个人信息的简单问答，记录版本、模型标签及真实结果。

**完成标准：** 关闭后再次打开仍能使用所选模型；如果需要离线运行，按 [官方 FAQ](https://docs.ollama.com/faq)核对本地模型与云功能设置，再断网验证自己的任务。

需要让 Ollama 保持本机模式时，可先阅读官方 FAQ 的关闭云功能说明；其中提供 `OLLAMA_NO_CLOUD=1` 环境变量选项，修改后须重启 Ollama。该设置不替代检查聊天界面、浏览器插件或其他工具的数据连接。

### 留下一份可复测记录

模型更新、换设备或改设置后，记下环境和同一条测试任务，才能分辨结果变化来自哪里。Ollama 官方本地接口可列出已安装模型及标签、摘要和量化信息；这个清单不能证明模型回答正确，也不能证明请求没有经过其他应用或云端。

```sh
ollama --version
curl http://localhost:11434/api/tags
```

只在运行 Ollama 的本机检查这个地址。不要为方便测试将未保护的模型服务端口开放到公网。Ollama 的云端功能、外部工具和聊天界面仍需单独确认数据流向。

| 记录项 | 填写内容 |
|---|---|
| 日期、操作系统和硬件 | 具体版本；内存/GPU只写本机可核对的信息 |
| Ollama 版本和模型标识 | 版本号、模型完整标签；需要复现时保存本地 `/api/tags` 输出，不含密钥 |
| 测试输入 | 一条不包含个人或机密信息的固定问题 |
| 预期证据 | 若检查知识库，写出应该引用的文件/段落；普通问答可留空 |
| 实际输出与失败 | 原样摘录必要部分，并标注错误、是否联网及使用的界面 |
| 下一次只改一项 | 例如模型标签、上下文设置或检索参数，避免一次改多项后无法定位原因 |

这是复测记录模板，不是本站运行模型所得的结果或性能测试。

## 第三步：确实需要时再添加聊天界面

需要浏览器界面时，先读 [Open WebUI 单机教程](/ai/ollama-openwebui/)，并核对 [Open WebUI 官方快速开始](https://docs.openwebui.com/getting-started/quick-start/)。先确认模型服务连接成功，再处理用户账号和数据持久化。长期使用应记录并固定所选版本，升级前备份应用数据。

**完成标准：** 界面能调用所选实例中已验证的模型；重启应用后仍能找到测试会话。暂时不要把服务直接开放到公网。

## 第四步：带着明确需求继续

- 需要了解更多方案：进入 [AI 文章目录](/ai/)，先核对教程日期、硬件与软件版本。
- 需要自动化助手：进入 [OpenClaw 七课路线](/openclaw/)，先了解工作区与权限，再接入平台。
- 需要知识库：按 [本地知识库样例](/ai/local-ai-knowledge-base-guide/)准备无敏感信息的小样本文档，验证答案能否指回原文，再扩大规模；不要把“已上传”当成“回答可靠”。

**完成标准：** 为每个新增功能准备一项验收任务，记录失败情况和回退方法，不用未测量的速度或准确率做判断。

若在本机保存 Open WebUI 的会话或配置，先按其官方部署说明确认数据卷和固定密钥的设置；密钥只保存在自己的环境中，不写入记录或截图，也不要直接把管理界面暴露到公网。

## 核查范围

路线资料核对日期：2026-10-23；三篇配套教程核对日期：2026-10-10。核查 Ollama 快速开始、本机模型列表 API、FAQ 和 Open WebUI 快速开始；本次补充的是可复测记录模板和本机端口/密钥边界。知识库脚本通过模拟 API 检查。本站未安装模型、运行容器或性能测试，也未使用任何模型 API 密钥。具体安装仍需核对所选版本说明并在自己的设备验收。
