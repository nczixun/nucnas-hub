## 型号级规格对照

下表把厂商公开页面中可确认的边界放在一起。它不是完整零售 SKU 清单：页面没有稳定、可交叉核实的地区货号/订单选项时，保留“购买前确认”，不猜测实际组合或随箱配件。

| 型号/平台 | 内存 | 存储接口 | 网络与扩展 | 购买前确认 |
|---|---|---|---|---|
| Apple Mac mini (2024)，M4 / M4 Pro | M4 规格列 16GB，选配 24GB/32GB；M4 Pro 列 24GB，选配 48GB/64GB。 | M4 列 256GB 起，选配至 2TB；M4 Pro 列 512GB 起，选配至 8TB。 | M4 为 Thunderbolt 4；M4 Pro 为 Thunderbolt 5；均有千兆以太网选配 10GbE。 | 选定芯片、内存、SSD 和网络选项；这些是出厂配置选项，本文不声称用户可自行升级。 |
| Beelink EQ14 N150 | 厂商页列 1 个 DDR4 SO-DIMM，页面标注最高 16GB。 | 双 M.2 2280 PCIe 3.0 插槽；存储容量/预装盘按实际销售选项确认。 | 页面提供双千兆或双 2.5GbE等选项，不能只凭 EQ14 型号名确定网卡组合。 | 订单里选定的网口版本、内存/SSD是否包含、适配器和保修范围。 |

Apple 与两款 N150 整机面向的系统和使用方式不同，不能按表格直接排名。厂商列出的槽位/选配不代表已验证盘位共存、散热、驱动、功耗、噪声或系统兼容；若要做 NAS 或软路由，先确认控制器、启动方式、驱动支持和备份安排。

## 阅读与选型边界

对每个候选记录完整型号、内存、SSD、系统、端口和售后范围。先确认软件是否支持所选系统，再检查容量与外设。比较时采用同地区、同配置、同日期的订单报价；本文不沿用无法追溯的春季促销价格。

## 把公开型号核对到实际订单

同一个产品名可能对应不同内存、SSD、网口或销售地区组合。把候选型号页与即将下单的配置选项分开记录；以下清单每个候选各填一份。尚未在订单页明确显示或与厂商资料冲突的项目，先记“待确认”，不要根据产品系列名推断。

| 核对项 | 记录内容 |
| --- | --- |
| 地区、日期、商品链接 | 待填写 |
| 页面完整型号与订单选项/SKU | 待填写；以结算页实际选择为准 |
| CPU、内存容量/类型、是否板载 | 待填写 |
| SSD是否包含、容量，以及可核对的插槽/规格 | 待填写 |
| 网口数量与速率、所选网卡版本 | 待填写 |
| 电源适配器是否随附；输入/输出和接口 | 待填写；页面冲突时单独书面确认 |
| 系统、保修和退换条件 | 待填写；按所在地区订单条款核对 |
| 证据位置与未解决问题 | 待填写；规格页、选项页或客服答复分开记录 |

如果型号页与实际订单选项不一致、关键配置没有写明，或电源参数仍冲突，先停在“待确认”，不要自行配电源或把未确认版本当作完整 SKU 推荐。收到实物后，再把标签型号与订单记录比对；这份表是购买前核对模板，不代表本站购买或验机。

## 如何验收自己的配置

先记录完整型号、CPU、内存、SSD、系统与驱动版本。用自己的主要任务确认功能和兼容性；如要比较速度，保留输入、设置与原始结果。厂商规格与编辑建议不代表本站实测，历史跑分、价格、噪音和体验描述没有原始证据的部分已撤下，旧版本可在仓库历史中追溯。
