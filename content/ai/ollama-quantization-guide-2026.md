选量化版本时，先确定要用的模型，再比较这个模型实际提供的标签。不要把“Q4”“Q8”直接换算成某张显卡能否运行，也不要把文件大小当作运行时内存需求。

## 同一模型的标签示例

下面以 Ollama 官方模型库中的 Qwen3 0.6B 为例。页面列出的文件大小是模型下载包的大小，便于比较标签；它不是运行时 RAM 或显存保证。模型库可能更新，选型时应以当前标签页为准。

| 官方标签 | 页面列出的文件大小 | 可以据此比较什么 |
| --- | ---: | --- |
| `qwen3:0.6b-q4_K_M` | 523 MB | 这一标签的下载文件体积 |
| `qwen3:0.6b-q8_0` | 832 MB | 同一模型的另一种量化标签 |
| `qwen3:0.6b-fp16` | 1.5 GB | 同一模型的 FP16 标签 |

标签来自 [Qwen3 官方模型标签列表](https://registry.ollama.com/library/qwen3/tags)，核对日期为 2026-10-28。其他模型的标签和文件大小不同，不能把这组数字套到 Qwen2.5、DeepSeek 或别的参数规模。

`Q4_K_M`、`Q8_0` 和 `FP16` 是不同权重表示方式的名称。具体格式涉及分组和张量处理；例如 llama.cpp 的格式说明列出每种类型的编码细节。因此，标签里的数字不是“整份模型所有数据都刚好使用 N 位”的保证，也不是模型准确率或速度的百分比。

## 按这四步选择

1. **先选模型和用途。** 在 [Ollama 模型库](https://ollama.com/library)确认确切模型与完整标签。模型名称、参数规模和量化标签是不同信息；同时检查模型许可与输入类型。
2. **只比较同一模型的实际标签。** 查标签页显示的下载大小与上下文信息。若目标标签不存在，不要从另一个模型名推测标签写法。
3. **先下载一个版本再运行。** 例如：

   ```sh
   ollama pull qwen3:0.6b-q4_K_M
   ollama ls
   ollama run qwen3:0.6b-q4_K_M
   ```

   这只是用来演示命令和标签的例子，不代表本站测过该模型，也不是对某台设备的推荐。若要比较 Q8 或 FP16，先在模型标签页确认完整标签，再单独拉取。
4. **用自己的任务验证，再决定是否保留。** 在相同软件版本、上下文设置和测试输入下，对照输出是否满足用途。用 `ollama ps` 看运行时显示的 CPU/GPU 分配；这只是当前设备的一次运行状态，不是跨设备的速度比较。

## 为什么文件大小不等于内存需求

运行时还会占用上下文缓存和软件本身所需的内存；上下文长度、并发数、其他已加载模型及 CPU/GPU 分配都会影响资源。Ollama FAQ 也说明并发和上下文会影响 RAM/显存需求。遇到内存不足时，先减少并发或上下文、停止不需要的模型，或选择标签页文件较小的版本，再观察自己的设备是否能完成目标任务。

不要仅凭型号或显存容量写下“N100 能跑某某模型”这样的结论。同一模型的文件标签只能提供下载体积参考；实际能否运行、响应速度和回答质量，应在目标设备和具体任务上分别确认。本站没有提供这组量化的实测跑分或质量排名。

## 常见问题

### Q4 一定比 Q8 快吗？

不能仅凭标签判断。执行速度还与处理器/显卡支持、内存带宽、后端、上下文和系统状态有关。按目标设备运行同一任务并记录设置，才得到这台设备的结果。

### 文件小就一定能装进显存吗？

不一定。下载文件大小不是显存占用；模型运行还会使用上下文缓存等资源。可先在 Ollama 中运行，再查看 `ollama ps` 的处理器分配和系统资源状态。

### 从哪里开始？

初次安装可先看 [Ollama 入门指南](/ai/ollama-beginner-guide-2026/)，再按模型库标签选择；需要验证本地文档问答时，继续看[本地知识库检查清单](/ai/local-ai-knowledge-base-guide/)。
