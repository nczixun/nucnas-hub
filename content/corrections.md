如果教程与当前软件行为不一致，先停在出问题的步骤，保留原有数据和配置。不要为了复现问题反复初始化磁盘或删除数据。

## 如何提交

1. 在相关文章底部点击“报告本文问题（GitHub）”。页面会打开本网站仓库的新建 Issue 表单，并预填文章标题和地址。
2. 登录 GitHub 后，补充问题段落、实际情况、设备与软件版本、可重复的操作步骤；有官方参考资料时附上链接。
3. 检查脱敏后自行提交。打开链接不会自动提交，也不会自动收集设备配置。

GitHub Issue 是公开讨论。不要填写密码、API 密钥、访问令牌、家庭公网地址、私人文档或含个人信息的完整日志。截图应遮盖无关信息。不要把公开纠错入口用于上传敏感漏洞细节。

也可直接进入[仓库问题列表](https://github.com/nczixun/nucnas-hub/issues)，先检查是否已有同一问题。本站目前没有匿名提交表单；没有 GitHub 账号时，可以先保存文章地址及上述信息，之后再提交。

## 怎样描述更容易核查

- **文章地址和位置：** 对应链接、标题或步骤编号。
- **原文和实际情况：** 哪句话或命令不成立，实际得到什么结果。
- **运行条件：** 软件完整版本、系统与必要的硬件信息。
- **期望修改：** 建议更正内容及可核对的官方来源。

提交是问题报告，不代表已经确认错误或完成修复。维护时会核对版本、来源和复现条件，再决定修正文案、补充限制或更新步骤；不承诺固定回复时间。
